## Aplicação das Ferramentas

As ferramentas foram utilizadas de acordo com as diferentes necessidades da Entrega 02.

O **GitHub** foi utilizado como principal ambiente de versionamento e colaboração, permitindo registrar as alterações realizadas pelos integrantes e manter o histórico de evolução dos artefatos.

O **Docsify** foi utilizado para estruturar e disponibilizar a documentação produzida pela equipe, facilitando a navegação entre as páginas e a apresentação dos artefatos.

O **Draw.io** foi utilizado na elaboração dos diagramas relacionados às atividades de modelagem, permitindo representar graficamente os elementos e relacionamentos definidos pela equipe.

O **Visual Studio Code** foi utilizado para criação, edição e organização dos arquivos Markdown e demais arquivos necessários para a documentação do projeto.

O **ChatGPT** foi utilizado como ferramenta de apoio durante as atividades da entrega, principalmente para esclarecimento de conceitos, organização de informações, revisão textual e apoio à análise das alternativas de modelagem. As sugestões produzidas pela ferramenta foram avaliadas pelos integrantes antes de sua utilização nos artefatos finais.

O **PlantUML** foi utilizado para gerar diagramas com sua linguagem de instrução eficiente.
