# 2. Desenho de Software

Este documento reúne os principais artefatos e decisões relacionados ao desenho de software do projeto **Fórum**, apresentando as representações estruturais e comportamentais desenvolvidas pela equipe durante a segunda etapa do projeto.

Nesta entrega, são apresentados modelos que auxiliam na compreensão da estrutura do sistema, na organização de seus componentes e nas interações entre os elementos que participam de seus principais fluxos. Os artefatos também servem como apoio para o desenvolvimento e para a evolução da solução proposta.

Os detalhes de cada artefato podem ser acessados nos respectivos documentos apresentados a seguir.

---

## Modelagem UML Estática

Nesta seção são apresentados os diagramas responsáveis por representar a **estrutura do sistema**, seus elementos e os relacionamentos existentes entre eles.

Os artefatos desenvolvidos são:

* [Diagrama de Componentes](./2.1.1.DiagramaComponente.md)
* [Diagrama de Classes](./2.1.2.DiagramaClasses.md)
* [Diagrama de Implantação](./2.1.3.DiagramaImplantacao.md)
